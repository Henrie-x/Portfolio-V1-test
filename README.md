Henry.Dev — Personal Portfolio

A personal developer portfolio showcasing my work, skills, services, and approach to building modern web experiences.

Overview

Henry.Dev is a portfolio website designed to introduce me as a frontend developer, highlight selected projects, and provide a way for visitors to get in touch.

Features

- Personal introduction and hero section
- Services section
- Featured projects section
- About section
- Skills and technology showcase
- Social links
- Contact form
- Dynamic content managed with JavaScript
- Navigation and footer sections

Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

Getting Started

1. Clone the repository:
   
   git clone https://github.com/Henrie-x/Portfolio-V1-test.git

2. Open the project folder.

3. Open "index.html" in your browser.

What I Practised

This project helped me practise structuring a multi-section website, styling layouts with CSS, organising JavaScript data, and dynamically rendering content into the DOM.
